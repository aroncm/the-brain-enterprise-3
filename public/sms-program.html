Baseball brAIn Text Alert Program

Baseball brAIn is an analytics platform operated by Clearmeadow Partners LLC and used by Major League Baseball club staff. It scores every pitch of every MLB game and marks the moment a pitching change is warranted. The platform itself requires a club account to sign in; this page describes the service and its text message program publicly.

How the text alerts work

Club staff with a Baseball brAIn account can opt in to receive a text message when the model reaches a pitching-change trigger in their club's live games.

  • Opt-in only. A user enters their mobile number and agrees to receive alerts inside their account settings, or provides written consent that their administrator records. A number is never enrolled without consent.
  • Frequency. Varies with the game schedule; typically a few messages per game day during the season.
  • Rates. Message and data rates may apply.
  • Opt out. Reply STOP to any message to opt out. Reply HELP for help.

Sample message

brAIn: AZ@LAD. Starter: PULL NOW at pitch 68. Driver: command decay. Relief options: 1.Arm 2.Arm 3.Arm. Reply STOP to opt out.
